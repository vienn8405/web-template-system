# 🚀 Web Template System

> Hệ thống template hoàn chỉnh để xây dựng website một cách có hệ thống và chuyên nghiệp

## 📖 Giới thiệu

Web Template System là một bộ tài nguyên tổng hợp giúp bạn (và AI) có thể nhanh chóng xây dựng các trang web chất lượng cao. Hệ thống này bao gồm design system, component library, layouts, patterns, và nhiều tài nguyên khác.

## 🎯 Mục đích

- ✅ **Consistency**: Đảm bảo tính nhất quán trong thiết kế và code
- ✅ **Speed**: Tăng tốc độ phát triển với templates và components có sẵn
- ✅ **Quality**: Đảm bảo chất lượng code và UX tốt nhất
- ✅ **Flexibility**: Linh hoạt, hỗ trợ nhiều tech stack khác nhau
- ✅ **AI-Friendly**: Được tối ưu để AI có thể dễ dàng sử dụng và tham khảo

## 📁 Cấu trúc thư mục

```
web-template-system/
├── 01-design-system/      # Hệ thống thiết kế (màu sắc, typography, spacing)
├── 02-components/         # Thư viện components UI
├── 03-layouts/            # Layout templates cho các loại trang
├── 04-patterns/           # Common patterns & best practices
├── 05-ai-prompts/         # Prompts & skills cho AI
├── 06-code-snippets/      # Code snippets sẵn dùng
├── 07-assets/             # Assets library (icons, images, fonts)
├── 08-tech-stacks/        # Cấu hình cho từng tech stack
├── 09-documentation/      # Documentation chi tiết
└── README.md              # File này
```

## 🚀 Quick Start

### Cho người dùng:

1. **Khám phá Design System**: Bắt đầu với `01-design-system/` để hiểu về màu sắc, typography, spacing
2. **Xem Components**: Tham khảo `02-components/` để xem các component có sẵn
3. **Chọn Layout**: Chọn layout phù hợp từ `03-layouts/`
4. **Áp dụng Patterns**: Sử dụng best practices từ `04-patterns/`

### Cho AI:

1. **Đọc Design System**: Load design tokens và guidelines từ `01-design-system/`
2. **Tham khảo Components**: Sử dụng component specs từ `02-components/`
3. **Sử dụng AI Prompts**: Tham khảo `05-ai-prompts/` để hiểu cách tạo components/pages
4. **Áp dụng Code Snippets**: Sử dụng code từ `06-code-snippets/` theo tech stack

## 🛠️ Tech Stack Support

Hệ thống này hỗ trợ nhiều tech stack:

- **React + Next.js** (với Tailwind CSS)
- **Vue + Nuxt** (với Tailwind CSS hoặc CSS Modules)
- **Vanilla HTML/CSS/JS** (không cần build tools)
- **Và nhiều stack khác...**

## 🎨 Design Philosophy

- **Mobile-First**: Thiết kế ưu tiên mobile trước
- **Accessibility**: Tuân thủ WCAG guidelines
- **Performance**: Tối ưu performance và loading speed
- **Maintainability**: Code dễ đọc, dễ maintain
- **Scalability**: Dễ dàng mở rộng và customize
